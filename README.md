# Tienda Sonido Vivo

Tienda online de instrumentos musicales (DSY1104 Desarrollo Fullstack II, Duoc UC).

| Carpeta | Contenido |
|---|---|
| `fase1/proyecto_etapa1_html` | Etapa 1: HTML + CSS + JavaScript vanilla (sin modificar) |
| `fase2/proyecto_Etapa2_REACT` | Etapa 2: React + Vite + Bootstrap 5 + pruebas con Vitest |
| `docs/ERS actualizado (v2)` | `ERS_v2.md`: especificación de requisitos |
| `docs/PRUEBAS UNITARIAS` | Informe de cobertura, salidas de consola y reporte HTML |

## Ejecutar la Etapa 2

```bash
cd fase2/proyecto_Etapa2_REACT
npm install
npm run dev        # http://localhost:5173
npm test           # pruebas unitarias
npm run coverage   # pruebas + cobertura
npm run build      # build de producción
```
